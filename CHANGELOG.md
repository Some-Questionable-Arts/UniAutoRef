# **⚠️ Breaking Changes for 2.0.0**

**The `[AutoFind]` attribute has been removed and replaced with `[AutoRef]`. Please see [README.md](https://github.com/Some-Questionable-Arts/UniAutoRef/blob/main/README.md) for usage instructions.**
**The legacy version containing [AutoFind] is still available in the legacy branch.**

# **Version 2.10**
### **Added:**
- **UI Panel (In `Tools -> UAR -> Window`).**
- **New feature: `Find All References In All Scenes` (Find all references to variables that marked with `[AutoRef]` attribute in ALL scenes (in buikd settings).**
- **HotKeys - `Find All References` - ALT + SHIFT + G, `Find All References In All Scenes` - ALT + SHIFT + T.**
- **Better debug. Now shows which scene is missing a variable. (And variable name, class name).**
